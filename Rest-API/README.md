# 📝 Quora Clone (Express + EJS)

A simple **Quora-like web application** built using **Node.js, Express.js, EJS, and Bootstrap**.  
Users can create posts, view posts, edit them, and delete them using RESTful routes and method override.

---

## 🚀 Features

- 📄 View all posts (Home Page)
- ➕ Create a new post
- 👁 View a single post
- ✏ Edit an existing post
- 🗑 Delete a post
- 🔐 User Registration & Login (basic, in-memory)
- 🎨 Clean UI inspired by Quora
- 🔁 RESTful routing with `method-override`

---

## 🛠 Tech Stack

- **Backend:** Node.js, Express.js  
- **Frontend:** EJS, HTML, CSS, Bootstrap  
- **Utilities:** UUID, Method-Override  
- **Icons:** Font Awesome
